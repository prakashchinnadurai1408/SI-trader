# SI-Trader strategy reviews

Use the [Arena review workflow](nifty100_weekly/AGENT_TOOLS.md#arena-strategy-review) for each new or materially changed strategy. Include Weekly, Monthly, research rankings and strategy experiments.

Ask the user to run the project's `/arena` skill with the reviewed evidence if it has not already been invoked. Give every solver the same fixed dates, decision-time evidence, costs, capital and risk constraints. Keep the final holdout out of strategy selection. Compare measured holdout performance and risks, and label unverified data or unmeasured results explicitly.

The Arena review is read-only. Promotion and execution follow the existing SI-Trader gates.
